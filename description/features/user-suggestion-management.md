# 用户意见管理

用户意见管理用于集中查看用户提交的建议，并为后续回复、采纳和可见性管理提供入口。当前阶段只在数据看板提供**新用户意见列表原型**。

---

## 当前原型入口

管理员点击“今日待办”中的“新用户意见”后，“当前赛季”工作区继续翻页并展示意见列表。点击列表页的返回按钮后，工作区统一回到当前赛季概览。

当前列表展示：

- 提交用户。
- 意见内容摘要。
- 提交时间。
- 新意见状态。

> [!NOTE]
> 原型展示模型参考 `user_suggestion` 的用户、内容和创建时间语义，但页面中的姓名、状态文案与示例内容均为本地演示数据。

---

## 当前限制

- 只能查看本地原型列表，暂不支持回复或修改可见性。
- 不写入用户建议表。
- 刷新页面后恢复原型数据。
