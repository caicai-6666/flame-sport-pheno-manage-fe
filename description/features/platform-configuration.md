# 平台配置页面

平台配置页面用于承载赛季、运动项目与挑战规则、商城商品等平台基础数据的管理能力。四个配置子页均已建立，其中已经明确的查询和写入能力使用真实接口。

---

## 页面进入方式

管理员点击顶部“平台配置”后：

1. 顶部胶囊导航中的白色滑块平滑移动到“平台配置”。
2. 数据看板沿水平方向向左离开可视区域。
3. 平台配置页面从右侧同步进入。
4. 左侧四个配置条目依次从左侧淡入导航栏，选中阴影在入场过程中同步显现。

返回“数据看板”时使用相反方向移动。

> [!NOTE]
> 数据看板、平台配置和用户事务始终保留在同一条三页轨道中，只改变轨道位置。这样可以保留图表实例、待办数量和未完成的审核状态。

---

## 当前配置导航

| 条目 | 管理范围 |
| --- | --- |
| 赛季基本信息 | 赛季名称、周期、运行状态、新建与活动海报 |
| 挑战等级 | 等级名称、新增与奖励积分维护 |
| 运动项目 | 项目创建、等级规则、凭证上传配置和可见状态 |
| 奖品 | 商品信息、兑换积分、图片与上下架状态 |

平台配置页使用左侧纵向导航组织以上四项，默认选中“赛季基本信息”。当前“赛季基本信息”展示赛季概览卡片，“挑战等级”展示等级名称和奖励积分卡片，“运动项目”展示项目卡片及各等级规则，“奖品”按积分升序展示商品并支持翻面编辑。

---

## 交互与无障碍

- 导航项使用按钮语义，当前模块通过 `aria-current="page"` 标识。
- 离开可视区域的页面使用 `aria-hidden` 和 `inert`，避免焦点进入隐藏页面。
- 系统启用减少动态效果时，滑块和页面轨道只保留极短的状态切换。
- 导航入场由页面激活状态驱动，因此每次重新进入平台配置都会再次播放，而不是只在首次加载时播放。
- 左侧条目切换时，选中背景、流光、边框和阴影作为同一层上下滑动到目标位置。
- “用户事务”已开放点击，并使用同一套模块页面布局承载自身的三个分类。

---

## 当前限制

- 赛季列表、新建赛季、挑战等级列表、新增等级、等级积分修改、运动项目创建、单项目单等级规则修改、项目状态修改，以及奖品列表、资料修改和上下架使用真实管理端接口。
- 尚未接入路由和浏览器历史记录。
- “赛季基本信息”已连接列表、创建和活动海报接口；海报可在脱离局部容器的长图查看器中滚动，并经前端 WebP 压缩转换后覆盖。
- “挑战等级”已连接全部等级列表、新增与奖励积分修改接口；积分修改经过二次确认，并由后端统一判断配置窗口。
- 运动项目基础目录已连接真实接口并保留隐藏项目；项目新增、单等级规则和可见状态均可持久化，项目详情不提供删除入口。
- 奖品已连接全部商品列表、受保护图片、新增、资料与图片局部修改和上下架接口，不提供删除入口。
