# 积分商城与奖品发放管理

积分商城管理用于维护商品并跟踪用户兑换后的奖品发放工作。当前阶段已提供**奖品配置卡片**和**待发放奖品列表**两类本地原型。

---

## 奖品配置

管理员进入“平台配置”并选择“奖品”后，可以查看按兑换积分从低到高组织的奖品卡片。卡片使用响应式瀑布流排列，并依据奖品图片的横竖比例呈现不同高度；宽内容区优先展示三列，较窄空间自动减少列数。

瀑布流最前方提供“新增商品”入口。点击后可填写商品名称、描述、兑换积分和图片；提交成功后，新商品默认展示，并根据积分自动加入现有升序列表。

卡片正面展示：

- 奖品图片。
- 奖品名称与描述。
- 兑换所需积分。
- 当前是否处于隐藏状态。

点击卡片后会原位翻转至背面，管理员可以修改奖品名称、描述、兑换积分和图片。保存积分变更后，卡片会在翻回正面后平滑移动至新的升序位置。

背面同时提供以下管理操作：

- **隐藏奖品：** 将商品状态调整为下架，管理端仍保留弱化卡片供后续恢复。
- **恢复展示：** 将已隐藏奖品重新调整为上架状态。
- **删除奖品：** 二次确认后从本地原型列表移除。

> [!WARNING]
> 当前删除没有兑换历史关联校验。真实业务中，已经产生兑换记录的商品应优先下架；物理删除资格必须以后端校验结果为准。

---

## 奖品发放入口

管理员点击“今日待办”中的“待发放奖品”后，“当前赛季”工作区继续翻页并展示待发放列表。点击列表页的返回按钮后，工作区统一回到当前赛季概览。

当前列表展示：

- 用户与兑换商品。
- 兑换所用积分。
- 兑换时间。
- 每条记录右侧提供无图标的“发放”按钮；点击后以退场动画从本地待办队列清除，并同步减少看板数量。

列表标题已经明确当前内容均为待发放任务，因此条目不重复展示“待发放”状态标签。

> [!WARNING]
> 当前仓库没有独立的兑换订单和奖品发放状态数据库文档，也没有对应管理端接口契约。页面数据均为本地演示数据，不得据此推断真实字段、订单状态或发放流程。

---

## 兑换记录查询

用户事务中的“兑换记录”复用运动记录智能查询面板，提供自然语言检索、动态表格、历史折叠和独立 Excel 导出。

兑换模式不展示记录图片，也不提供表格行点击行为。当前响应仅由本地数据模拟，用于确认界面交互；不执行发放状态修改，也不读取真实积分流水。

## 当前限制

- 奖品资料编辑、隐藏、恢复和删除均只作用于本地数据，不会持久化。
- 图片当前仅以 Data URL 进行本地预览，尚未执行文件上传。
- “发放”操作当前只清理本地原型队列，不会写入服务端；刷新页面后记录恢复。
- 不修改商品库存或用户积分。
- 刷新页面后恢复原型数据。
