# 积分商城与奖品发放管理

积分商城管理用于维护商品并跟踪用户兑换后的奖品发放工作。当前阶段只在数据看板提供**待发放奖品列表原型**。

---

## 当前原型入口

管理员点击“今日待办”中的“待发放奖品”后，“当前赛季”工作区继续翻页并展示待发放列表。点击列表页的返回按钮后，工作区统一回到当前赛季概览。

当前列表展示：

- 用户与兑换商品。
- 兑换所用积分。
- 兑换时间。
- 待发放状态。
- 每条记录右侧提供“已发放”按钮；点击后以退场动画从本地待办队列清除，并同步减少看板数量。

> [!WARNING]
> 当前仓库没有独立的兑换订单和奖品发放状态数据库文档，也没有对应管理端接口契约。页面数据均为本地演示数据，不得据此推断真实字段、订单状态或发放流程。

## 当前限制

- “已发放”当前只清理本地原型队列，不会写入服务端；刷新页面后记录恢复。
- 不修改商品库存或用户积分。
- 刷新页面后恢复原型数据。
