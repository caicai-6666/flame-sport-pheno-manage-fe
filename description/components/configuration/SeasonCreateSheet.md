# SeasonCreateSheet

`SeasonCreateSheet` 是“全部赛季”容器内的新建赛季表单，从容器底部升起并采集赛季基础信息。

> [!NOTE]
> 当前只完成表单交互和数据提交事件，尚未连接真实创建接口。

---

## 组件职责

- 输入最长 64 个字符的赛季名称。
- 使用“年 / 月 / 日”三列滚轮选择开始日期和结束日期。
- 根据所有已有赛季中最晚的结束日期限制开始日期，最早只能选择其结束后的第一天。
- 开始日期变化后，将结束日期自动设置为下一个自然月的 `1` 日。
- 根据开始日期动态限制结束日期滚轮，不展示早于开始日期的年份、月份和日期。
- 使用单列滚轮选择要求的项目个数，默认值为 `3`。
- 字段标题不重复展示完整日期或项目个数，当前值只由滚轮中央选项表达。
- 在年份或月份变化后自动修正超出当月天数的日期。
- 校验赛季名称非空，并校验结束日期不早于开始日期。
- 支持关闭按钮、取消按钮和点击遮罩取消。

表单优先将开始日期默认设为下一个自然月的 `1` 日；如果该日期不晚于已有赛季中最晚的结束日期，则自动改为该结束日期的下一天。结束日期默认选择开始日期下一个自然月的 `1` 日。开始年份滚轮从最早可选日期所在年份延伸 4 年；结束年份额外延伸 1 年以支持跨年。

## Props

| 名称 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `minimumStartDate` | `String` | 否 | `''` | 最早允许的开始日期，格式为 `YYYY-MM-DD`；当前调用方传入已有最新赛季结束后的第一天 |

---

## 事件

| 事件名 | 参数 | 触发时机 |
| --- | --- | --- |
| `cancel` | 无 | 点击关闭、取消或表单外遮罩时 |
| `submit` | 赛季表单对象 | 所有前端校验通过并点击“创建赛季”时 |

`submit` 参数结构：

```js
{
  name: '金秋燃动 · 九月赛季',
  startDate: '2026-09-01',
  endDate: '2026-10-01',
  requiredProjectCount: 3,
}
```

> [!IMPORTANT]
> 以上是前端展示模型，不代表后端接口字段已经确定。接入接口时应由服务适配层转换字段命名和数据类型。

---

## 布局与滚动

表单固定在“全部赛季”内容容器内部，从底部向上进入，不推动根页面。较矮或较窄视口下仅滚动表单正文，头部与操作区保持可见。

系统启用减少动态效果时，关闭底部升起动画和按钮位移动画。
