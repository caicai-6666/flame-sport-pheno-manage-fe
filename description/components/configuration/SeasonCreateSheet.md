# SeasonCreateSheet

`SeasonCreateSheet` 是“全部赛季”容器内的新建赛季表单，从容器底部升起并采集赛季基础信息。

> [!IMPORTANT]
> 表单由父组件调用真实创建接口；只有服务端返回 `201 Created` 且响应校验通过后才会关闭。

---

## 组件职责

- 输入最长 64 个字符的赛季名称。
- 使用“年 / 月 / 日”三列滚轮选择开始日期和结束日期。
- 根据所有已有赛季中最晚的结束日期限制开始日期，最早只能选择其结束后的第一天。
- 开始日期变化后，将结束日期自动设置为满一个自然月的最早结束日；起止日均计入赛季，因此以顺延一个自然月的日期再回退一天计算。
- 根据最短一个自然月的持续时间动态限制结束日期滚轮，不展示早于最早结束日的年份、月份和日期。
- 使用单列滚轮选择要求的项目个数，默认值为 `3`；可见项目少于 3 个时采用可见项目总数。
- 要求项目数滚轮最多展示当前可见项目总数，并在提交时再次校验，不允许配置超过实际可选范围的数量。
- 字段标题不重复展示完整日期或项目个数，当前值只由滚轮中央选项表达。
- 在年份或月份变化后自动修正超出当月天数的日期。
- 校验赛季名称非空，并校验赛季持续时间不少于一个自然月。
- 创建按钮使用 3 秒限时二次确认：首次点击完成校验并切换为“确认创建”，再次点击才提交；超时或修改任意字段会自动取消确认。
- 支持关闭按钮、取消按钮和点击遮罩取消。
- 提交期间锁定输入框、全部滚轮、关闭和取消操作，并在提交按钮内展示加载动画。
- 接口失败时保留当前输入，通过 `submitError` 展示后端安全提示；字段再次变化时清除旧错误。

表单优先将开始日期默认设为下一个自然月的 `1` 日；如果该日期不晚于已有赛季中最晚的结束日期，则自动改为该结束日期的下一天。结束日期默认选择满一个自然月的最早结束日，例如 `2026-09-01` 对应 `2026-09-30`、`2026-09-15` 对应 `2026-10-14`；月末顺延时先收敛到目标月末，再按包含结束日的口径回退一天。开始年份滚轮从最早可选日期所在年份延伸 4 年；结束年份额外延伸 1 年以支持跨年。

## Props

| 名称 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `minimumStartDate` | `String` | 否 | `''` | 最早允许的开始日期，格式为 `YYYY-MM-DD`；当前调用方传入已有最新赛季结束后的第一天 |
| `maximumProjectCount` | `Number` | 是 | 无 | 当前允许的要求项目数上限，调用方取可见项目总数与 `255` 的较小值 |
| `submitting` | `Boolean` | 否 | `false` | 父组件是否正在提交创建请求；为 `true` 时锁定表单 |
| `submitError` | `String` | 否 | `''` | 父组件传入的接口错误提示 |

---

## 事件

| 事件名 | 参数 | 触发时机 |
| --- | --- | --- |
| `cancel` | 无 | 点击关闭、取消或表单外遮罩时 |
| `clear-error` | 无 | 管理员修改任意表单字段，需要清除旧接口错误时 |
| `submit` | 赛季表单对象 | 所有前端校验通过，并在 3 秒内完成第二次确认时 |

`submit` 参数结构：

```js
{
  name: '金秋燃动 · 九月赛季',
  startDate: '2026-09-01',
  endDate: '2026-09-30',
  requiredProjectCount: 3,
}
```

以上是表单事件的前端模型。`seasonCreateApi` 负责将字段转换为后端蛇形命名，并校验创建响应。

---

## 布局与滚动

表单固定在“全部赛季”内容容器内部，从底部向上进入，不推动根页面。较矮或较窄视口下仅滚动表单正文，头部与操作区保持可见。

系统启用减少动态效果时，关闭底部升起动画和按钮位移动画。
