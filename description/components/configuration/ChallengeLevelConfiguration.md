# ChallengeLevelConfiguration

`ChallengeLevelConfiguration` 是平台配置中“挑战等级”的概览组件，以运动奖章式卡片展示平台已有等级及其挑战奖励。

> [!NOTE]
> 当前使用 `project_level` 数据库文档中的示例数据，尚未接入查询接口。

---

## 组件职责

- 以响应式网格排列全部挑战等级。
- 在网格第一位展示“新建等级”加号卡片，点击后从容器底部升起新建表单。
- 在卡片主体突出等级名称。
- 在独立底栏展示达成该等级挑战后的奖励积分。
- 使用青铜、白银和黄金的专属配色区分原型等级。
- 卡片进入时依次淡入，悬停时轻微抬升并移动表面光泽。
- 点击卡片后原位翻转，在背面修改该等级的奖励积分。
- 校验奖励积分为非负整数，保存后更新本地卡片数据并翻回正面。
- 内容超过可用高度时只滚动组件内部，不移动根页面。

组件当前不负责停用、删除、规则维护或接口请求。等级新增和奖励修改只保存在当前页面状态中，刷新后不会保留。

---

## 当前数据结构

| 字段 | 用途 |
| --- | --- |
| `id` | 等级稳定标识 |
| `name` | 等级名称，对应 `project_level.name` |
| `reward` | 达成挑战后的奖励积分，对应 `project_level.reward` |
| `palette` | 原型卡片的主色、辅色和文字颜色 |

> [!IMPORTANT]
> 接入接口时应由页面或服务适配层转换数据，展示组件不根据数据库结构推断接口地址及响应格式。

---

## 交互与无障碍

- 卡片正面使用按钮语义，点击后沿纵轴翻转到奖励编辑表单。
- 点击“新建等级”后，背景卡片停止交互；表单校验通过时插入新卡片，并按奖励积分从低到高重新排列。
- 背面自动聚焦并选中奖励积分，支持直接输入后按回车保存。
- 点击“返回”或按下 `Esc` 放弃草稿并翻回正面；点击“保存修改”通过校验后更新显示值。
- 翻转过程中只允许当前可见的一面接收焦点和交互。
- 系统启用减少动态效果时，取消卡片入场、抬升和光泽位移动画。
- 页面普通文字不可选中，奖励积分输入框保留文本选择能力。

新增表单会校验等级名称非空、名称不重复，以及奖励积分为非负整数。名称唯一性的最终约束仍由后端与数据库负责。
