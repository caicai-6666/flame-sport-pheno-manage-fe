# SportProjectConfiguration

`SportProjectConfiguration` 是平台配置中“运动项目”的概览组件，使用工作台共享的完整项目目录展示可见和隐藏项目，并在项目详情中展示当前已有的等级规则。

> [!NOTE]
> 项目 ID、名称、运动说明、图标和状态已经接入真实列表；规则在打开项目后按等级读取，并可通过真实写接口修改单个等级配置。

---

## 组件职责

- 以卡片网格展示项目接口返回的全部项目，隐藏项目保留卡片并使用弱化状态。
- 复用数据看板初始化时建立的项目目录和图标对象 URL，不重复请求项目列表或图标。
- 卡片正面直接展示接口返回的运动说明；空说明使用明确回退文案。
- 只有管理员打开某个项目或新建项目时才按需取得挑战等级列表；打开已有项目后，以最多 5 个并发请求读取该项目各等级规则。
- 项目与等级组合使用缓存；关闭后再次打开不重复请求，未打开项目不预取规则。
- 新建等级成功后废弃组件中旧的等级快照和项目详情状态；再次打开项目时补取新等级及其规则，已有组合继续复用共享缓存。
- 新等级初始化规则中的 `null` 要求值显示为“待设置”，不会把有效的指标骨架误判为接口错误。
- 在项目网格第一位展示“新建运动项目”入口；首次点击时若等级目录尚未建模，先请求 `/project-level/list`，成功后再从容器底部打开三步创建表单，后续直接复用等级快照。
- 新建表单统一收集项目资料、接口返回的全部等级规则和凭证上传配置；指标名称和每个等级的全部指标值必填，所有等级规则固定可见且不提供隐藏控件，副描述与备注仍按接口契约选填。凭证组合通过单一下拉菜单选择普通凭证或“月初 + 月末记录”，配置卡由组件自动生成并固定启用。项目资料阶段不提供状态选择，新项目固定为隐藏状态，创建成功后将新卡片插入已有项目之前。
- 在卡片正面展示项目图形、项目名称、简短说明和已配置等级数量。
- 为已有项目卡片叠加独立的深色流动星河；按项目 ID 稳定生成不同星轨，并保留文字区的暗色可读性遮罩。新建项目入口不使用星河。
- 星云跨越紫、粉、蓝、青、金五种宇宙色，并将服务端透明黑色项目图标转为冷调亮色轮廓，保证深色卡片和规则页标题中的图标清晰可见。
- 点击项目卡片后，将卡片从原位置放大到内容区中央并同步翻转。
- 在卡片背面按等级分栏展示项目规则。
- 将每条规则统一渲染为“指标 — 要求值”，例如“每日步数 — 6000 步”。
- 每个等级规则卡使用单面布局，同时展示挑战副描述、指标要求和规则备注。
- 在卡片背面提供隐藏和恢复显示操作，不提供项目删除入口。
- 在卡片背面的项目名称右侧提供行内修改入口，编辑态平滑扩展出确定与取消按钮。
- 每个等级卡正面提供“修订”入口，可修改挑战副标题、规则备注和该等级已有指标的值。
- 规则内容超过详情卡片高度时，只滚动等级规则区域，不移动管理端根页面。
- 等级数量形成多行时使用独立的纵向间距，并让每张卡按自身内容高度排版；指标较多的高卡片不会与下一行阴影粘连。

组件当前负责真实项目基础信息概览与本地等级规则、项目维护原型，不独立发起项目列表请求。

## 当前数据结构

### 项目

| 字段 | 用途 |
| --- | --- |
| `id` | 项目的稳定标识 |
| `name` | 项目名称 |
| `description` | 接口返回的项目运动说明；为 `null` 时使用空说明状态 |
| `palette` | 项目卡片的主色、辅色与文字色 |
| `iconPaths` | 当前原型使用的内联图形路径 |
| `iconDataUrl` | 共享目录加载的图标对象 URL，或本地新增的图片预览地址 |
| `status` | 项目启停状态 |
| `levels` | 该项目配置的挑战等级规则 |
| `uploadConfigs` | 新建项目的凭证上传配置 |

### 等级规则

| 字段 | 用途 |
| --- | --- |
| `id` | 等级标识 |
| `name` | 等级名称 |
| `tone` | 等级视觉主题 |
| `requirements` | 规则指标数组 |
| `requirements[].label` | 指标名称，对应规则内容中的 `label` |
| `requirements[].value` | 要求值，对应规则内容中的 `value` |
| `subDesc` | 接口 `sub_desc` 返回的挑战副描述，可为 `null` |
| `ruleNote` | 接口 `rule_note` 返回的规则备注，可为 `null` |
| `status` | 等级规则启停状态 |

> [!IMPORTANT]
> 共享目录覆盖 `project` 的 ID、名称、运动说明、图标和状态。项目详情通过等级列表与 `project/rule` 按 `project_id + level_id` 组合规则，不根据数据库结构猜测未返回字段。

## 交互与状态

- 项目卡片进入页面时依次淡入。星河默认缓慢迁移；悬停或键盘聚焦时，卡片轻微放大、抬升并增强阴影，星尘视差、星云宽度、流速和拖尾同步增强。
- 项目 ID 决定星轨分布、流向、倾角和运动速度，同一项目在列表与放大正面保持同一视觉身份，不同项目不会复制相同轨迹。
- 项目详情翻到规则背面、打开新建表单或卡片离开可视区域后暂停星河；离屏卡片延迟释放 WebGL 上下文。系统启用减少动态效果时只绘制静态画面。
- 点击“新建运动项目”后，项目列表停止交互；尚无等级模型时先展示加载状态，请求成功后创建表单才从内容区底部升起。空等级或加载失败不会打开不完整表单，入口保留提示并允许重试。
- 创建表单完成全部校验后，创建按钮进入 3 秒二次确认态；再次确认后，新项目立即出现在新增入口之后，并可翻面检查刚填写的等级规则。确认超时、返回上一步或修改表单会自动恢复普通创建状态。
- 点击卡片后，详情卡片的放大与三维翻转同时开始。
- 详情打开期间，背景项目网格使用 `inert` 停止接收焦点和点击。
- 点击“返回”、点击详情遮罩或按下 `Esc` 时，卡片同步翻回正面并缩回原位置。
- 点击“隐藏项目”后调用真实状态接口；服务端成功后项目仍保留在管理端列表中，并以灰阶卡片和“已隐藏”标记展示。
- 已隐藏项目的背面操作会变为“恢复显示”，服务端成功后恢复启用。提交期间禁用退出和重复操作，失败时保持原状态并展示后端安全提示。
- 项目名称默认就在黑白粗边、硬阴影的只读框体中展示且不出现光标，框体按名称在 3D 变换前的实际排版宽度自适应。点击右侧“修改”后，同一个框体平滑伸长并反色进入编辑态；选区感知的闪烁竖线通过镜像文字宽度与横向滚动量定位，可跟随鼠标点击、方向键和 Home/End，文字被选中时暂时隐藏。只有输入已经为空仍继续删除时才短促抖动。操作区同步扩展出“确定”和“取消”，按钮使用与名称轨道相同的高度并按硬阴影校正视觉中心；固定高度与预留阴影间距避免下方等级说明和整体标题布局跳动。名称未变化时不请求接口；提交成功后同步当前卡片和工作台共享项目目录，名称冲突或配置窗口关闭时保留草稿。
- 名称编辑与等级规则修订互斥；编辑期间按下 `Esc` 优先取消名称修改，不关闭项目详情。
- 点击等级卡正面的“修订”后，在项目详情上方打开独立修订卡；原等级网格保持尺寸和位置不变。
- 修订卡保持左右等高布局：左侧编辑挑战副标题与规则备注，右侧编辑指标值；指标过多时只滚动右侧指标列表，标题与左侧面板保持稳定。
- 副描述、指标与备注始终在同一正面展示，空副描述或备注使用明确占位文案。
- 指标名称、顺序和值类型均保持只读；编辑器根据原值自动选择文本、数字、布尔或 JSON 控件，不提供类型切换。
- 原值为 `null` 时使用首次配置文本框，留空仍保存为 `null`，填写后按文本值提交。
- 第一次点击“保存配置”进入 3 秒确认态，第二次点击才调用真实修改接口。成功后以服务端完整响应原地更新共享规则模型，失败则保留草稿和安全提示。
- 保存按钮始终锚定在修订卡右下方；确认态只向左扩展按钮宽度并切换提示，不改变按钮的右侧位置。
- 提交期间禁用取消、返回和遮罩关闭，防止响应成功后丢失目标等级上下文。
- 指标编辑期间按下 `Esc` 会优先退出编辑模式，不关闭项目详情。
- 系统启用减少动态效果时，不播放位移、放大和翻转过渡。

> [!WARNING]
> 当前管理端不提供删除项目入口。历史数据可能引用项目，退出普通可选口径应使用隐藏状态。

## Props

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `projects` | `Array` | `[]` | 工作台共享的全部项目目录，包含可见与隐藏项目 |
| `loading` | `Boolean` | `false` | 项目目录是否仍在加载 |
| `error` | `String` | `''` | 项目目录加载错误；非空时禁用本地新增入口 |
| `projectRuleCatalog` | `Object \| null` | `null` | 工作台共享的项目等级规则缓存；已有组合不会重复请求 |
| `projectLevelCatalogRevision` | `Number` | `0` | 等级创建版本；变化时使本组件的等级快照失效 |

## 事件

| 事件名 | 参数 | 触发时机 |
| --- | --- | --- |
| `project-created` | `{ project, iconFile }` | 创建接口返回并通过校验后，同步服务端项目与本次 PNG 到工作台共享目录 |
| `project-updated` | 项目基础信息 | 项目名称或可见状态修改成功后 |

## 新增项目数据

创建表单二次确认后，组件调用真实 multipart 创建接口。只有服务端返回 `201 Created` 后才将数据适配为项目卡片模型：

- `project` JSON 用于写入名称、说明和初始隐藏状态；处理后的 PNG 通过独立 `icon_file` 字段上传。
- `project_rules` 列表中的每条规则按 `level_id` 合并到对应等级，`rule_content` 转换为“指标 — 要求值”列表。
- `project_upload_configs` 列表暂存于项目对象，等待后续上传配置维护界面使用。

创建成功后使用服务端生成的项目主键和唯一 `icon_url` 同步工作台共享目录；当前会话直接复用刚上传的 PNG，刷新后通过图标中转接口读取。创建失败保留表单草稿，不插入虚假本地项目。项目名称、单等级规则及隐藏、恢复显示同样持久化到后端。
