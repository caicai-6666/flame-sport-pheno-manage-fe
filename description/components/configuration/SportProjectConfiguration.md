# SportProjectConfiguration

`SportProjectConfiguration` 是平台配置中“运动项目”的概览组件，以项目卡片组织运动类型，并在放大翻转后的背面展示各挑战等级要求。

> [!NOTE]
> 当前项目及规则使用本地原型数据，尚未接入查询或维护接口。

---

## 组件职责

- 以卡片网格展示走路、跑步、羽毛球、篮球、爬山和健身六个运动项目。
- 在项目网格第一位展示“新建运动项目”入口，并从容器底部打开三步创建表单。
- 新建表单统一收集项目资料、各等级规则和多条凭证上传配置；创建成功后将新卡片插入已有项目之前。
- 在卡片正面展示项目图形、项目名称、简短说明和已配置等级数量。
- 点击项目卡片后，将卡片从原位置放大到内容区中央并同步翻转。
- 在卡片背面按等级分栏展示项目规则。
- 将每条规则统一渲染为“指标 — 要求值”，例如“每日步数 — 6000 步”。
- 在卡片背面提供隐藏、恢复显示和删除项目操作。
- 在卡片背面提供指标值编辑模式，可分别修改每个等级下的要求值。
- 规则内容超过详情卡片高度时，只滚动等级规则区域，不移动管理端根页面。

组件当前负责项目及等级规则概览与本地新增原型，不负责修改、删除或接口请求。

## 当前数据结构

### 项目

| 字段 | 用途 |
| --- | --- |
| `id` | 项目的稳定标识 |
| `name` | 项目名称 |
| `description` | 卡片上的项目说明 |
| `palette` | 项目卡片的主色、辅色与文字色 |
| `iconPaths` | 当前原型使用的内联图形路径 |
| `iconDataUrl` | 新建项目上传图标的本地预览地址 |
| `status` | 项目启停状态 |
| `levels` | 该项目配置的挑战等级规则 |
| `uploadConfigs` | 新建项目的凭证上传配置 |

### 等级规则

| 字段 | 用途 |
| --- | --- |
| `id` | 等级标识 |
| `name` | 等级名称 |
| `tone` | 等级视觉主题 |
| `requirements` | 规则指标数组 |
| `requirements[].label` | 指标名称，对应规则内容中的 `label` |
| `requirements[].value` | 要求值，对应规则内容中的 `value` |
| `subDesc` | 等级规则副描述 |
| `ruleNote` | 等级规则备注 |
| `status` | 等级规则启停状态 |

> [!IMPORTANT]
> 接入接口后，应由页面或服务适配层组合 `project`、`project_level` 与 `project_rule` 数据。组件不根据数据库结构猜测接口响应格式。

## 交互与状态

- 项目卡片进入页面时依次淡入，悬停时轻微放大、抬升并增强阴影。
- 点击“新建运动项目”后，项目列表停止交互，创建表单从内容区底部升起。
- 创建表单提交后，新项目立即出现在新增入口之后，并可翻面检查刚填写的等级规则。
- 点击卡片后，详情卡片的放大与三维翻转同时开始。
- 详情打开期间，背景项目网格使用 `inert` 停止接收焦点和点击。
- 点击“返回”、点击详情遮罩或按下 `Esc` 时，卡片同步翻回正面并缩回原位置。
- 点击“隐藏项目”后，将本地 `status` 调整为停用；项目仍保留在管理端列表中，并以灰阶卡片和“已隐藏”标记展示。
- 已隐藏项目的背面操作会变为“恢复显示”，点击后将本地 `status` 恢复为启用。
- 点击“删除项目”后，背面显示二次确认层；取消或按下 `Esc` 返回规则详情，确认后先关闭详情卡片，再从本地列表移除项目。
- 点击“修改指标”后，所有等级卡片中的要求值切换为输入框；指标名称和指标顺序保持只读。
- 点击“保存指标”时拒绝空值，并将草稿写回对应等级的 `rule_content[].value`；点击“取消修改”放弃草稿。
- 指标编辑期间按下 `Esc` 会优先退出编辑模式，不关闭项目详情。
- 系统启用减少动态效果时，不播放位移、放大和翻转过渡。

> [!WARNING]
> 当前隐藏和删除均为本地原型操作。删除前尚未校验赛季参与、项目规则、上传配置、凭证及历史统计引用；接入真实接口前必须补齐这些校验，且历史数据已引用的项目应优先停用而不是物理删除。

## 本地新增数据

创建表单提交后，组件会将数据适配为项目卡片模型：

- `project` 字段用于卡片正面。
- 每条 `project_rule` 按 `level_id` 合并到对应等级。
- `rule_content` 转换为背面的“指标 — 要求值”列表。
- `project_upload_config` 暂存于项目对象，等待后续上传配置维护界面使用。

当前新增、指标值修改、隐藏、恢复显示和删除都只存在于内存中，刷新页面后不会保留。
