# SeasonBasicConfiguration

`SeasonBasicConfiguration` 是平台配置中“赛季基本信息”的概览组件，以卡片网格展示当前赛季和历史赛季。

> [!IMPORTANT]
> 赛季列表已接入 `GET /season/list`。该接口返回赛季状态值及中文名称，但不返回要求项目数或参与人数。

---

## 组件职责

- 按时间倒序整齐排列全部赛季。
- 通过受保护的赛季列表接口读取全部赛季，保留后端 `start_date DESC, end_date DESC, id DESC` 顺序。
- 组件首次挂载时请求列表；平台配置尚未进入时不提前挂载，首次查询后由两层 `KeepAlive` 保留组件和数据。
- 区分加载、空列表与失败状态；失败时保留错误提示和重试入口。
- 在赛季网格第一位展示独立的“新建赛季”加号入口，该入口不计入赛季总数；点击后从容器底部升起新建表单。
- 新建表单校验通过后调用真实创建接口，服务端返回 `201` 后使用其 ID、状态和实际项目数插入赛季卡片。
- 查找所有已有赛季中最晚的结束日期，并将其下一天传给新建表单作为开始日期下限。
- 接收工作台已经建立的可见项目数量，结合接口的 `255` 上限计算新建赛季要求项目数的滚轮上限；不为此重复请求项目列表。
- 在每张卡片展示赛季名称、起止日期和后端返回的赛季状态，不展示参与人数。
- 使用整张“赛事通行证”彩色封面承载名称、日期和视觉状态，不再保留统计底栏。
- 为不同赛季分配独立双色主题，封面不叠加圆圈或跑道线条，保持画面简洁。
- 已结束赛季的正面使用灰阶和透明度弱化；进行中赛季使用更高饱和度、双层高亮描边、轻微上浮和高对比状态胶囊建立唯一视觉焦点。
- 根据内容区宽度自动调整网格列数，窄屏下收敛为单列。
- 赛季数量超出可用高度时只滚动卡片网格所在内容区，不移动根页面。
- 将已有赛季作为只读概览卡片展示，不响应点击，也不再放大或翻转。

组件负责赛季列表和创建请求，但尚未接入修改或删除接口。创建成功的数据已写入后端，刷新后会由列表接口重新取得。

## 当前数据结构

| 字段 | 用途 |
| --- | --- |
| `id` | 赛季在列表中的稳定标识 |
| `name` | 赛季名称 |
| `startDate` | `YYYY-MM-DD` 开始日期 |
| `endDate` | `YYYY-MM-DD` 结束日期 |
| `status` | 后端状态原值：`0`～`3` |
| `statusName` | 后端状态对应的中文文案 |
| `statusTone` | 卡片视觉状态：`upcoming`、`active`、`settling` 或 `ended` |
| `palette` | 卡片封面的主色、辅色与预留深色辅助色 |

> [!IMPORTANT]
> API 模块将后端字段转换为驼峰形式，并验证日期、ID、重复记录以及 `status/status_name` 对应关系；组件将状态值映射为视觉类名并补充色板。

---

## 交互与状态

- 点击“新建赛季”入口后，背景列表停止交互，底部表单升入容器。
- 表单校验通过后进入提交态；只有服务端返回并通过响应校验时才插入新卡片、发出 `create` 事件并关闭。
- 查询与创建卡片都使用后端状态：`0` 未开始、`1` 进行中、`2` 结算中、`3` 已结束，前端不根据日期覆盖服务端结论。
- 创建期间锁定表单和关闭动作以防重复提交；`409`、`422`、`500` 或响应异常时保留表单及输入内容并展示错误。
- 列表请求期间禁用新建入口，避免在尚未取得已有赛季日期边界时创建重叠赛季；请求失败后需先重试。
- 从赛季基本信息切换到其他配置页时组件只被停用而不卸载；再次返回不重跑 `onMounted` 请求。
- 新建表单会裁掉已有最新赛季结束日期及其之前的选项；新增一张未来赛季后，下次创建的日期下限会继续向后推进。
- 赛季卡片进入页面时依次淡入。
- 鼠标悬停时卡片轻微放大、上浮并增强阴影，同时提高层级避免被相邻卡片遮挡。
- 已结束赛季悬停时略微恢复清晰度，但仍保持弱于当前赛季的视觉层级。
- “进行中”状态展示白底高对比状态胶囊、呼吸圆点、流动封面光带和缓慢呼吸的双层边缘光；“结算中”保留独立暖色边框与静态暖色圆点，避免与当前赛季争夺视觉焦点。
- 赛季卡片不提供翻面或详情层；当前唯一可点击卡片是“新建赛季”入口。
- 系统启用减少动态效果时，停止入场、漂移和呼吸动画。

## 事件

| 事件名 | 参数 | 触发时机 |
| --- | --- | --- |
| `create` | 赛季表单对象 | 新建表单校验通过并点击“创建赛季”时 |

## Props

| 名称 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `visibleProjectCount` | `Number` | 否 | `0` | 工作台可见项目模型的当前条目数 |
| `visibleProjectListReady` | `Boolean` | 否 | `false` | 可见项目列表是否已成功取得；未就绪或数量为 0 时禁用新建入口 |
