# SeasonBasicConfiguration

`SeasonBasicConfiguration` 是平台配置中“赛季基本信息”的概览组件，以卡片网格展示当前赛季和历史赛季。

> [!NOTE]
> 当前赛季列表使用本地原型数据，尚未接入查询接口。

---

## 组件职责

- 按时间倒序整齐排列全部赛季。
- 在赛季网格第一位展示独立的“新建赛季”加号入口，该入口不计入赛季总数；点击后从容器底部升起新建表单。
- 新建表单提交后立即生成一张本地赛季卡片，参与人数和各项目人数均从 `0` 开始。
- 查找所有已有赛季中最晚的结束日期，并将其下一天传给新建表单作为开始日期下限。
- 在每张卡片正面展示赛季名称、起止时间、激活状态和参与人数。
- 使用“赛事通行证”结构组织卡片：彩色运动封面承载名称、状态和周期，独立数据底栏承载参与人数。
- 为不同赛季分配独立双色主题，封面不叠加圆圈或跑道线条，保持画面简洁。
- 已结束赛季的正面使用灰阶和透明度弱化，进行中赛季保持完整色彩以建立视觉焦点。
- 根据内容区宽度自动调整网格列数，窄屏下收敛为单列。
- 赛季数量超出可用高度时只滚动卡片网格所在内容区，不移动根页面。
- 点击卡片后将其视觉副本放大到内容区中央，并同步翻转展示该赛季各运动项目参与人数。

组件当前不负责调用赛季创建接口，也不负责修改、删除或数据请求。新增卡片只存在于当前页面状态中，刷新页面后不会保留。

---

## 当前数据结构

| 字段 | 用途 |
| --- | --- |
| `id` | 赛季在列表中的稳定标识 |
| `name` | 赛季名称 |
| `startDate` | 展示用开始日期 |
| `endDate` | 展示用结束日期 |
| `status` | 卡片视觉状态，当前使用 `upcoming`、`active` 和 `ended` |
| `statusLabel` | 中文状态文案 |
| `participantCount` | 正式参与该赛季的用户数量 |
| `palette` | 卡片封面的主色、辅色与底栏数字颜色 |
| `projectEnrollments` | 卡片背面的运动项目参与人数与柱体颜色 |

> [!IMPORTANT]
> 接入接口后，应由页面或服务适配层将后端字段转换为以上展示模型，组件不直接推测接口响应结构。

---

## 交互与状态

- 点击“新建赛季”入口后，背景列表停止交互，底部表单升入容器。
- 表单校验通过时先插入新卡片，再向上层发出 `create` 事件并关闭；关闭、取消、点击遮罩或按下 `Esc` 时直接收回。
- 新增卡片暂按本地自然日与赛季起止日期比较，显示“待开始”“进行中”或“已结束”；接入接口后应以后端 `season.status` 为准。
- 新建表单会裁掉已有最新赛季结束日期及其之前的选项；新增一张未来赛季后，下次创建的日期下限会继续向后推进。
- 赛季卡片进入页面时依次淡入。
- 鼠标悬停时卡片轻微放大、上浮并增强阴影，同时提高层级避免被相邻卡片遮挡。
- 已结束赛季悬停或键盘聚焦时略微恢复清晰度，但仍保持弱于当前赛季的视觉层级。
- “进行中”状态展示呼吸圆点和缓慢移动的封面光带。
- 点击卡片后，详情卡片从原位置向容器中央放大的同时执行三维翻转，不等待放大结束。
- 背面使用横向柱状图展示走路、跑步、羽毛球、篮球、爬山和健身的参与人数。
- 点击“返回”、点击详情遮罩或按下 `Esc` 时，卡片翻回正面、缩回原位置和遮罩淡出同步进行。
- 详情打开期间，背景赛季列表使用 `inert` 停止接收焦点和点击。
- 系统启用减少动态效果时，停止入场、漂移和呼吸动画。
