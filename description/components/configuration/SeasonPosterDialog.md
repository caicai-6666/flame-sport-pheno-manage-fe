# SeasonPosterDialog

`SeasonPosterDialog` 用于在“赛季基本信息”内查看和更换全局唯一的活动海报，支持对长海报进行独立滚动查看。

> [!IMPORTANT]
> 用户选择的原图不会直接上传。组件先调用浏览器图片处理模块压缩并转换为 WebP，管理员确认后才提交。

---

## 组件职责

- 打开后通过受保护接口读取当前 WebP 海报。
- 通过 `Teleport` 挂载到页面根层，脱离“全部赛季”的定位和裁剪上下文。
- 在固定视口高度的滚动区域中按原始宽高比展示长图，不拉伸或撑大赛季容器。
- 将加载圆圈固定在预览区中心；图片完成解码后通过透明度、轻微模糊和位移缓慢浮现。
- 复用受控滚轮工具归一化滚轮单位，并把单帧位移限制为 `48px`，避免大幅滚动跳过长图内容。
- 接受 JPEG、PNG 或 WebP 原图，限制原图最大 10 MiB。
- 在浏览器中限制图片尺寸和像素数，分档压缩并转换为 WebP，同时保留透明通道。
- 在上传前展示处理后的海报预览、像素尺寸及压缩前后体积。
- 更换按钮使用 3 秒限时二次确认，并通过按钮颜色、缩放、文案切换和倒计时线平滑过渡确认状态。
- 第二次确认后提交 `multipart/form-data`，成功后重新读取服务端最终 WebP。
- 处理加载失败、无海报、编码失败、上传失败、认证失效和结果未知的网络中断。
- 在弹窗关闭、海报替换或组件卸载时释放 Blob URL，避免大图长期占用内存。

组件不负责持久化文件或生成自定义图片路径，文件安全校验、EXIF 方向修正和原子覆盖仍由后端完成。

## 使用方式

```vue
<Teleport to="body">
  <Transition name="season-poster">
    <SeasonPosterDialog
      v-if="isPosterDialogOpen"
      @close="isPosterDialogOpen = false"
    />
  </Transition>
</Teleport>
```

## 主要状态与异常处理

| 状态 | 页面行为 |
| --- | --- |
| 正在读取 | 在没有可用旧图时展示读取动画 |
| 读取失败或不存在 | 展示后端安全提示、重新读取入口，并继续允许选择新海报 |
| 正在前端处理 | 禁用文件选择，提示“正在压缩并转换” |
| 待上传 | 展示本地 WebP 预览、尺寸、体积变化及确认按钮 |
| 等待二次确认 | 按钮切换为“再次确认更换”，3 秒后自动恢复 |
| 正在上传 | 锁定关闭和重复提交，按钮显示加载动画 |
| 上传成功 | 清除本地预览，并重新读取服务端重编码后的最终图片 |
| 上传失败 | 保留待上传预览和错误信息，允许管理员再次处理 |

> [!WARNING]
> 网络中断时后端可能已经完成覆盖。组件不会声称请求失败，而是提示管理员先重新读取当前海报，再决定是否重复上传。

弹窗不再提供独立的“取消更换”按钮。管理员可以通过右上角关闭按钮、遮罩或 `Escape` 退出；重新选择文件也会取消上一轮二次确认。
