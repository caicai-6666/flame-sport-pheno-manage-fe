# 修改奖品上下架状态接口

本文档描述平台配置奖品卡片根据服务端状态展示，并在管理端修改商品可见状态的前端链路。

---

## 接口定义

**请求：** `PATCH /flame/admin/api/product/{product_id}/status`

开发模式由统一请求层添加 `/dev` 前缀。请求体只提交严格整数状态：

```json
{
  "status": 0
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `product_id` | `integer` | 正整数商品主键 |
| `status` | `integer` | `0` 下架，`1` 上架；不接受字符串、布尔值或其他整数 |

商品上下架不受激活赛季配置修改窗口限制。下架只改变 `product.status`，不会删除商品或历史兑换关联。

## 成功处理

接口以 `200 OK` 返回完整商品资料。前端校验商品 ID、目标状态、名称、描述、积分和图片地址后，才把卡片状态切换为服务端最终值。

- `status = 1`：正面正常展示，背面按钮显示“下架”。
- `status = 0`：卡片使用弱化样式并标记“已下架”，背面按钮显示“上架”。
- 请求期间按钮禁用并显示“上架中”或“下架中”，避免重复写入。
- 写请求不自动重试；后端支持相同状态幂等提交。

## 错误处理

| 状态 | 页面行为 |
| --- | --- |
| `404` | 显示“奖品不存在”或后端安全提示，保留原状态 |
| `422` | 拒绝非法商品 ID 或状态 |
| `303` | 由统一认证层清理失效令牌并返回登录视图 |
| `500` 或网络失败 | 显示安全错误，保留原状态且不自动重试 |
| 完整响应字段不合法或状态不一致 | 视为响应异常，保留原状态 |
