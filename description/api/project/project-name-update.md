# 修改运动项目名称接口

本文档描述管理员在运动项目详情中修改项目名称时使用的接口，以及名称写回工作台共享项目目录的规则。

---

## 接口定义

**请求：** `PATCH /flame/admin/api/project/{project_id}/name`

开发模式由统一请求层添加 `/dev` 前缀。请求体只包含整理后的项目名称：

```json
{
  "name": "力量训练"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `project_id` | `integer` | 正整数项目主键 |
| `name` | `string` | 去除首尾空白后为 1～64 个字符 |

## 成功处理

接口以 `200 OK` 返回完整项目基础信息。前端校验项目 ID、名称、说明、图标地址和状态后，才更新当前详情卡并通过 `project-updated` 事件写回工作台共享目录。

名称成功变化后，项目卡片、数据看板项目名称、审核场景项目关联和后续赛季配置复用同一份新名称。写请求不自动重试；提交期间禁止退出编辑态和重复提交。

## 页面交互

- 项目名称右侧的“修改”按钮进入行内编辑态，并选中原名称。
- 编辑态从原按钮位置平滑扩展出“确定”和“取消”按钮，不改变规则列表布局。
- 空名称、超过 64 字或与当前目录中其他项目同名时先在前端提示。
- 服务端拒绝修改时保留输入内容；按 `Esc` 或点击“取消”恢复服务端已保存名称。
- 名称没有变化时直接退出编辑态，不发送请求。

## 错误处理

| 状态 | 页面行为 |
| --- | --- |
| `404` | 展示“运动项目不存在”或后端安全提示 |
| `409` | 展示名称冲突、配置窗口关闭或多激活赛季提示，并保留编辑草稿 |
| `422` | 拒绝非法项目 ID 或名称 |
| `303` | 由统一认证层清除失效令牌并返回登录视图 |
| 其他错误 | 展示通用修改失败提示，不做乐观更新 |
